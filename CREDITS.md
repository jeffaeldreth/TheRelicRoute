# Credits

## Artwork

- **Logo** (`src/libraryCatalog/TheRelicRoute.jpg`): generated with Google's generative AI tools.
  The small sparkle in its corner is Google's mark. The MIT license in this repository covers the

- [JavaFX / OpenJFX](https://openjfx.io) for the user interface
- [MariaDB Connector/J](https://mariadb.com/kb/en/about-mariadb-connector-j/) to talk to the database

These are not included in this repository. Each is used under its own license; see the project
